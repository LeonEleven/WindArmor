# WindArmor
## 项目介绍
本项目名字是WindArmor，是一个飞行机器人项目，机器人外形效仿钢铁侠，目标是可以像钢铁侠那样通过四肢的涵道风扇提供动力悬空并飞行。
目前只在双臂的肩部安装了4个小米cybergear微电机，分别控制双臂的前后、左右活动。机器人手掌张开向下，掌心挖空安装了涵道风扇提供飞行动力。
## 软硬件介绍
1. 树莓派5
> 装有Ubuntu24.04.4系统。
2. 微雪2-CH CAN HAT+扩展板
3. 4个小米cybergear微电机
> 两臂各两个微电机，控制手臂的左右抬起与前后抬起（手臂自然状态是垂直向下，左、右抬最多90度，前、后抬起最多也是90度），从机器人的右臂到左臂依次：右臂右抬起/放下的微电机canid=1；右臂前/后抬起/放下的微电机canid=2；左臂前/后抬起/放下的微电机canid=3；左臂左抬起/放下的微电机canid=4；
> 四个微电机通过串联的形式接在微雪2-CH CAN HAT+扩展板的can10上。
4. Hiwonder IMU模块。
> 水平内置在机器人上躯干中央，X轴正向向着机器人的正面朝向，Y轴向着机器人左臂方向，Z轴垂直于地面。
5. ros2 版本
> jazzy
## 前置项目
目前已经实现了两个前置项目：fan_ros2_ws和imu_cybergear_2.0_ros2_ws。
### fan_ros2_ws（ https://github.com/LeonEleven/fan_ros2_ws ）
这个项目实现了在树莓派上控制单个涵道风扇。风扇通过杜邦线接在扩展板上对应的32（GPIO12）和34（GND）上（需要注意树莓派在接入微雪扩展板后可用的gpio）。默认风扇启动时档位为最低油门脉宽800，手动按键可以增减脉宽，到1200时风扇才启动，最大是2200。
### imu_cybergear_2.0_ros2_ws（ https://github.com/LeonEleven/imu_cybergear_2.0_ros2_ws ）
这个项目实现了IMU与cybergear微电机功能的整合与联动，微电机可以根据IMU各个方向的倾斜状态而跟随运动（即IMU向前/后倾斜，则两臂也向前/后运动；IMU向左倾斜，则左臂向左运动，右臂也向左直至到零位；MU向右倾斜，则右臂向右运动，左臂也向右直至到零位；以及上述的复合情况）。亦可通过人工手动在键盘上按键设置IMU和微电机的初始零点位置以及操控微电机的位置、速度等。
