# ALG-006 — Normalized Actuator Coordination / Control Allocation

本文是 ALG-006 Task Spec v1，只冻结 ALG-005 最终 ordinary recovery intent 到单轴 normalized
执行器协调请求的纯软件资格。它不是 Candidate 实现、真实执行器矩阵、motor position
projection、fan thrust model、硬件安全包线或硬件授权。共享接口以
[Flight Control API](../FLIGHT_CONTROL_API.md) 为准；完整 fixture、场景、容差和判定见
[Algorithm Benchmark v1 / ALG-006 Profile v1](../ALGORITHM_BENCHMARK.md#13-alg-006-profile-v1)。

## 2. 单一目标与能力边界

ALG-006 v1 唯一新增能力是：保留 ALG-005 process outcome 的安全语义，并把合法 ordinary
final recovery intent 转换成可解释、受限、对称且保留 residual 的单轴 normalized allocation。

```text
ALG-005 process outcome
  -> timeout / validity gate
  -> ordinary final recovery intent u
  -> normalized request r
  -> common normalized allocation q
  -> motor_pitch_group + left_fan + right_fan + residual
```

本任务不重新设计 ALG-005 recovery process，不重调 `Kp/Kd`，不增加输入 filter 或输出
shaping，不处理 roll、多轴分配、pitch/roll 冲突、differential-fan roll control、真实
torque/thrust allocation、硬件标定、真实执行器安全、最大可恢复扰动或 sim-to-real 等价性。
roll、multi-axis、axis coupling、combined saturation 和 axis priority 明确保留给 ALG-007。

## 3. ALG-005 输入语义与优先级

ALG-006 输入不得只是没有来源状态的 `float`。task-local seam 必须携带或等价保留：

- `final_recovery_intent`：ALG-005 最终 intent；
- `phase`：至少能区分 ordinary `STABLE` 与 `TIMED_OUT`；
- `timeout_latched`：保留 ALG-005 latch；
- 外部 state/measurement freshness、health、validity 和 `dt` 已通过的事实，或等价的前置
  validation/fail-close disposition。

安全优先级冻结为：

1. ALG-005 `TIMED_OUT` / 已锁存 timeout；
2. external invalid、stale、unhealthy、unknown 或 illegal `dt`；
3. ordinary input validity 和 inherited envelope；
4. normalized authority validity；
5. ordinary normalized allocation。

ALG-005 `TIMED_OUT` 的 exact-zero `u=0.0` 是 stop sentinel，不是 ordinary zero request；它
必须旁路 ordinary allocator，保留 timeout latch，并在 controller integration 返回精确
`FlightCommand.safe_stop()`。ordinary `STABLE` 的合法 `u=0.0` 才产生 `NEUTRAL`。两者不得
因数值相同而合并。外部故障同样在 ordinary allocation 前拒绝，并保持现有 validation layer
分类与 safe-stop 语义。

## 4. Normalized allocation contract

task-local 观测量冻结为：

| 量 | 单位 / 范围 | 语义 |
| --- | --- | --- |
| `final_recovery_intent u` | inherited intent unit；ordinary `[-0.10,+0.10]` | ALG-005 ordinary 最终 intent |
| `normalized_request r` | dimensionless；`[-1,+1]` | `r = u / 0.10` |
| `motor_pitch_group` | dimensionless；`[-1,+1]` | normalized recovery-coordinate 中的逻辑 motor group request |
| `left_fan` | dimensionless；`[0,1]` | task-local allocation magnitude |
| `right_fan` | dimensionless；`[0,1]` | task-local allocation magnitude |
| `residual` | dimensionless signed normalized request | 未被共同 authority 承载的显式余量 |
| `status` | enum | `NEUTRAL/ALLOCATED/SATURATED/INFEASIBLE/FAIL_CLOSED` |

`0.10 intent unit` 只继承 ALG-004 Profile v1 的 frozen abstract output envelope，不表示任何
actuator capability。ordinary `u` 非 finite 或超出该 envelope 时必须 `FAIL_CLOSED`，不得
静默 clamp。`motor_pitch_group` 不是 encoder rad 或 torque，也不定义 `left_pitch` /
`right_pitch` 的真实方向。fan allocation 不是 RPM、推力比例或可执行 PWM。

`ALG006-NORMALIZED-ALLOCATION-v1` 冻结三个 synthetic software authority：

```text
motor_authority      dimensionless [0,1]
left_fan_authority   dimensionless [0,1]
right_fan_authority  dimensionless [0,1]
```

它们只是 qualification fixture，不是 measured actuator authority、torque/thrust capability 或
真实硬件 characterization；它们是 scenario input，不是 Candidate 可按场景调节的 configuration。
bool、string、`None`、NaN、Inf、unknown 或超出 `[0,1]` 的值均非法。对合法 ordinary request：

```text
r = u / 0.10
q = min(abs(r), motor_authority, left_fan_authority, right_fan_authority)

motor_pitch_group = sign(r) * q
left_fan = q
right_fan = q
residual = r - sign(r) * q
```

其中 `sign(r)` 对正/负值为 `+1/-1`，ordinary `r==0` 单独走 exact neutral 分支。状态为：

- `r==0`：`NEUTRAL`，全部 allocation 和 residual 精确为零；
- `r!=0` 且 `q==abs(r)`：`ALLOCATED`；
- `0<q<abs(r)`：`SATURATED`；
- `r!=0`、authority 均合法已知且 `q==0`：`INFEASIBLE`；
- 任一 contract-invalid input，或上游 timeout/fail-close disposition：`FAIL_CLOSED`，不得复用
  prior ordinary allocation；timeout 原因和 latch 仍须独立可观察。

该规则表示“没有 actuator substitution 证据时，只接受所有必需 normalized resource 共同可
承载的 request magnitude”。它不表示 motor/fan physical effectiveness 相同，不表示两类
执行器可互相等效补偿，也不能用 `q` 预测 thrust、torque 或机器人恢复能力。

## 5. Symmetry、priority 与 conflict boundary

v1 软件优先级为：timeout/fail-close、输入合法性、authority bounds、左右单轴对称、最大化
共同可执行 normalized magnitude、保留 residual。普通 single-axis allocation 必须满足
`left_fan==right_fan`。交换左右 synthetic fan authority 后，公共 `q`、motor group、fan pair
和 residual 必须 mirror-consistent。

Profile v1 不定义 motor-first、fan-first、left-first、right-first 或 physical weighted matrix。
一侧剩余 authority 不得产生 differential fan request；这种 axis conflict/substitution 语义属于
ALG-007。`SATURATED` 是合法 ordinary result，本身不触发 history reset。

## 6. Motor group、hardware mapping 与 Level B

现有 `motor_ids`、`motor_signs` 和 position soft limits 是 hardware/software mapping 与安全配置
事实，不是 recovery-effectiveness evidence。ALG-006 v1 不推导 motor torque effectiveness、
normalized request → rad scale、recovery intent → `left_pitch/right_pitch` sign、pitch motors
相对 effectiveness 或 lift motor recovery 语义；`left_lift/right_lift` 不获得新的 allocation
含义。

当前 `FlightCommand.motor_positions_rad` 要求 absolute rad target，但仓库没有足够证据冻结
normalized motor allocation 到合法 rad target 的 projection。因此：

- **Level A — HARD GATE**：直接评分 normalized allocation seam；
- **Level B — HARD GATE**：继续评分 factory、state/command validation、完整 motor frame、合法
  fan frame、safe-stop；ordinary command 允许继续使用 ALG-005 的当前完整 motor position hold
  与左右 fan `0.0`；不得从 payload 反推 allocation，也不得宣称 allocation 已物理执行；
- **Level C — optional preview only**；
- **Level D — HARD GATE**：执行 `ALG006-NORMALIZED-ALLOCATION-v1` scripted sequence；
- **Level E — inheritance HARD GATE only**：不新增 ALG-006 actuator dynamic plant；正式资格须
  原样重跑 ALG-005 Profile v1 Level E；
- **Level F — NOT AUTHORIZED / NOT EXECUTED**。

若未来评审要求非零 executable `FlightCommand` payload，必须先独立冻结 projection contract，
不能任意选择 `0.1 rad`、motor sign 或 fan PWM。该缺口是明确 blocker/follow-up design item，
不能通过修改公开 Flight API 或猜测硬件映射在本 Task 内解决。

## 7. Reset、history 与 fail-close

normalized allocator v1 必须无状态：禁止 moving average、hysteresis、slew limiter 和
previous-command fallback。ALG-004 已负责 abstract output shaping，底层 manager 保留执行级
soft limits、rate/ramp、watchdog、lease、E-STOP 和最终否决权。

显式 `reset()` 保持 ALG-001～005 既有语义，并清除任何 ALG-006 task-local observation/cache。
allocation-layer `FAIL_CLOSED` 或 external actuator-availability `INFEASIBLE` 在 controller
integration 必须产生精确 `FlightCommand.safe_stop()`、不复用 prior allocation，并 cold-reset
ordinary task-local history。若 ALG-005 timeout 已 latch，任何 ALG-006 transient failure 都不得
清除 latch；仍只有 explicit reset 可以清除。validation-layer reject 仍由前置校验拒绝。

## 8. Verification 与 inheritance

未来 Candidate 必须执行 Profile v1 的 D00～D12、Level A/B/D Hard Gates，并在自身最终路径上
重新运行未修改的 ALG-001、ALG-002、ALG-003、ALG-004 和 ALG-005 Profile v1 inheritance。
ALG-005 inheritance 包括 A/B/D/E；历史 Candidate Result 不代替本轮 execution。

不得为 allocation 重调 ALG-001/002 gains、修改 ALG-003 filter、绕过 ALG-004 magnitude/slew、
修改 ALG-005 thresholds/timers，或把 TIMED_OUT zero 当 ordinary intent。完整 scenario 和
Hard Gate 定义只以 Profile v1 为准。

## 9. Hardware evidence gaps

以下事实保持 **UNKNOWN / NOT VERIFIED**，必须由未来 hardware characterization、经评审的
projection contract 或独立 Level F evidence 解决：

- real motor torque effectiveness 与 motor recovery direction；
- normalized motor request → position rad projection；
- fan RPM、fan thrust、fan thrust direction 和 fan moment arm；
- left/right fan physical symmetry；
- motor/fan relative recovery authority；
- actuator latency、rate/deadband under recovery load 与 cross-coupling；
- safe actuator recovery envelope 与 maximum recoverable disturbance；
- real closed-loop Balance Recovery 与 sim-to-real equivalence。

synthetic authority 和 fixture 数字不得填充成上述真实参数。当前 hardware access 为 `NO`，
authorization 为 `NONE`，hardware validation 为 `NOT AUTHORIZED / NOT EXECUTED`，real actuator
safety 与 real Balance Recovery 均为 `NOT VERIFIED`。

## 10. Pass / Fail 与 future-task boundary

正式资格只有在 Profile v1 全部 Hard Gates 和 ALG-001～005 inheritance 都 PASS 后，才可记为
`ALG-006 QUALIFIED`。Candidate 实现前不得创建 Candidate Result 或预填 PASS。

本任务明确不实现 ALG-006 Candidate、production projection 或 Candidate Result；不修改
Flight API、Runtime authority/ownership、motor/fan manager、hardware mapping、soft limits、fan
ramp、watchdog、E-STOP 或 safe-stop。ALG-007 继续负责 roll/multi-axis、axis coupling、combined
