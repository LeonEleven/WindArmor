## 2. 单一目标与链路

唯一新增能力：在不改变 ALG-001 姿态反馈、ALG-002 阻尼、ALG-003 输入噪声鲁棒性语义的前提下，对继承得到的 abstract recovery intent 增加软件层输出约束，使其幅值有限、变化率有限、符号切换受控，并具有明确的 reset / fail-close 历史语义。

```text
FlightState -> ALG-001 attitude feedback -> ALG-002 damping
            -> ALG-003 input noise robustness -> requested abstract intent
            -> ALG-004 output shaping -> shaped abstract intent
```

task-local shaping seam 的概念输入是 `requested_intent, dt`，输出是 `shaped_intent`。它只供算法 qualification 观察，不是新增公开 Flight API。ALG-004 不重新解释 raw gyro、pitch 或 pitch-rate，不重调 `Kp/Kd`，不以新输入 filter 冒充输出整形。

## 3. Profile v1 数值契约

冻结 `U = 0.10 intent unit`、`S = 2.0 intent unit/s`。令 `r_i` 为请求、`t_i = clamp(r_i, -U, +U)` 为当前 target、`y_i` 为输出、`dt_i` 为当前正有限秒数。cold start、`reset()`、controller-layer fail-close 或非法 `dt` 后的上一输出基线精确为 `y_(-1)=0.0 intent unit`，首个合法输出也必须受 slew 约束。每次合法 update 必须同时满足：

```text
y_i is finite
abs(y_i) <= U + tol(y_i, U)
abs(y_i - y_(i-1)) <= S * dt_i + tol(abs(y_i - y_(i-1)), S * dt_i)
min(y_(i-1), t_i) - tol(y_i, min(y_(i-1), t_i)) <= y_i
y_i <= max(y_(i-1), t_i) + tol(y_i, max(y_(i-1), t_i))
```

最后两项要求输出朝 target 移动或保持，不能人为远离或越过当前 target 产生 shaping 自身的 overshoot；它们不声称机器人闭环单调。`tol(a,b)=1e-9+1e-6*max(abs(a),abs(b))`，`abs_tol=1e-9 intent unit`、`rel_tol=1e-6`；有效反向的 `eps_sign=2e-3 intent unit`。仅允许这些 Profile 固定容差，不得额外放宽。计算有效反向时先删去 `abs(y_i)<=eps_sign` 的样本，再统计剩余相邻符号变化；插零不能隐藏一次真正反向。

这些 `U/S` 仅是 **ALG-004 Profile v1 synthetic software qualification envelope**，不是 CyberGear rad、motor velocity、torque、PWM、fan thrust、机器人实际安全 envelope 或真实执行器 capability；本任务不建立物理语义映射。

## 4. 正常行为与 Hard Gates

`ALG004-FIXTURE-v1` 直接给 shaping seam 输入 deterministic synthetic `requested_intent`，不再以 pitch/rate 构造 ALG-004 自身场景，不使用运行时随机数。默认 `dt=0.020 s`；全部正常 steady、step、reversal 和继承 gate 在 `0.020`、`0.037`、从 `0.020` 开始连续交替的三种合法 `dt` 下分别执行。交替相位跨 segment 不重启，每个完整 run 各重复三次。所有显式正负镜像逐帧检查奇对称；所有合法帧检查 finite、幅值、当前真实 `dt_i` 的 slew 与 directed transition。

Profile 冻结 N00 中性、P01–P04/N01–N04 稳态、S01/S02 step、S03 完整反向、S04 高频反向。其互不抵消的 Hard Gates 为：

- **Neutral / Saturation**：零请求保持零；`±0.20` 请求的 target 只为 `±0.10`。
- **Steady Signal Preservation**：P01–P04/N01–N04、S01/S02 最终常值段最后三帧有符号均值与非零 target 同号，幅值位于 `0.80*abs(target)` 至 `abs(target)+tol`；恒零或长期过度衰减 FAIL。
- **Step Response**：P01–P04 和 S01/S02 从非零 target 生效首帧起，前三帧内至少一帧同号且达到 target 幅值的 50%；记录 1-based `frames_to_50pct` 和从变化边界累计至该帧结束的 synthetic elapsed time。这不是实机响应 SLA。
- **Full Reversal**：S03 的反向段前六帧内达到新 target 相反方向的 50%（`±0.10` 时为 `0.05`），末三帧均值满足 80%..100% 稳态门槛；不能瞬时跳过 slew，也不能长期滞留旧方向或零附近。
- **High-frequency Reversal**：S04 的 `TV(candidate)<=0.60*TV(target)=1.32 intent unit`，有效符号反向数 `<=4`；同时逐帧满足全部输出契约。该 gate 与稳态信号保留独立，不容许单纯 clamp 跳变或持续小幅正负 ping-pong 通过。

每项门槛均在三种合法 `dt` 下独立判定。任何 Hard Gate FAIL 即 `ALG-004 NOT QUALIFIED`；比较指标不得抵消。

## 5. 输入失效、reset 与历史隔离

合法 `dt` 为正有限秒数，不是绝对时间戳。`0`、`-0.01`、NaN、`+Inf/-Inf` 均须由 controller-layer 精确返回合法 `FlightCommand.safe_stop()`，清除 ALG-003 输入/filter history 和 ALG-004 shaped-output history，不输出旧 intent；下一合法输入等价于 fresh cold start。

沿用 Flight API/Runtime validation：valid IMU 的必要 pitch/rate 为 `None` 或 NaN/Inf 时先由 `validate_flight_state()` 拒绝，不调用 controller；合法 unobserved/invalid IMU、IMU stale、`required_inputs_fresh=false`、必要 motor unavailable/invalid/stale/unhealthy、E-STOP 不明确为 false 时由 controller safe-stop。每个 controller-layer 故障前须先建立非零 ALG-003 + ALG-004 history，故障后下一合法输入必须等价于 `reset()` 加同一输入的 fresh cold start。validation-layer 拒绝后由 harness 调用 `reset()` 检查恢复，不把未调用 controller 误记为 controller PASS。

`ALG004-R01` 用 P04 建立接近 `+0.10` 的 history，reset 后 N02 必须等价于全新 controller 的 N02 cold run。`ALG004-R02` 分别执行 `P02 -> reset -> N02` 与 `N02 -> reset -> P02`：同场景结果与顺序无关，P02/N02 逐帧镜像；不得复用 ALG-003 history、ALG-004 output、旧普通 command/cache/latch。reset 不修改 Runtime、IMU zero、authority、E-STOP 或硬件状态。

## 6. 继承资格与 FlightCommand

未来 Candidate 必须在当前 **post-shaped abstract intent** 上重新运行未修改的 `ALG001-FIXTURE-v1`、`ALG002-FIXTURE-v1`、`ALG003-FIXTURE-v1` 的能力、fail-close、reset、factory、Level B、noise suppression、signal preservation 和 trend preservation gate；历史 PASS 不可代替。原输入、阈值、关系方向和历史 Result 保持不变；ALG-003 对有历史候选的继承观测窗口规则仍适用。ALG-003 Profile 中只因“ALG-004 是未来能力”而禁止最终 output shaping 的那一项，在当前 ALG-004 inheritance gate 自然 supersede，不作为失败条件；其余行为资格与 ALG-005+ 禁令继续有效。单纯 `output *= 0.1` 若破坏继承语义必须 FAIL。

普通 Level B `FlightCommand` 仍只复制**当前合法完整** motor feedback position hold，左右 fan 为 `0.0`；电机键完整，fan payload 合法，命令通过 `validate_flight_command()`。safe-stop 使用现有精确无载荷契约。不得把 shaped intent 编码为 motor/fan direction；真正的 abstract intent 到四电机和两风扇分配属于 ALG-006。Runtime、底层软限位、watchdog、lease、E-STOP、安全退出和最终否决权保持不变。

## 7. Verification、结论与未来边界

正式 Level A、Level B、Level D 都是 **HARD GATE**。Level A 评分 task-local seam 的数值与历史；Level B 独立评分 factory、state/command validation、完整 frame 和 safe-stop；Level D 组织确定性软件序列回放，不是 dynamic simulation。Level C 可作补充 preview；Level E 不要求，可信动态 benchmark 从 ALG-005 起；Level F 未授权、未执行。实现前不创建 Candidate Result 或虚构 PASS。

ALG-003 负责输入侧 pitch/pitch-rate noise robustness、估计/filtering 和小波动活动抑制；ALG-004 只负责已生成 intent 的幅值、slew、step/sign reversal 连续性和 output-history reset。ALG-004 不新增 pitch/rate filter，不改 ALG-001/002 `Kp/Kd`，不加 integral/anti-windup，不实现 ALG-005 recovery process/state machine、ALG-006 allocation、ALG-007 multi-axis 或 ALG-008 full disturbance recovery；也不改 Flight API、Runtime、adapters、default/teaching controller、hardware manager、映射和安全机制。

`Actuator-safe Output` 只是 roadmap 能力标签。即使将来获得 `ALG-004 QUALIFIED`，也**只**证明 abstract control intent 在冻结 synthetic fixture 中满足数值幅值、变化率、信号保留、符号切换和历史重置约束，较适合后续 actuator integration；不证明 `REAL ACTUATOR SAFE`、CyberGear/fan/PWM 安全、allocation 或方向正确、真实执行器动态安全、机器人可恢复平衡或真实 Balance Recovery。当前 Candidate `NOT IMPLEMENTED`，真实硬件验证 `NOT AUTHORIZED / NOT EXECUTED`。
