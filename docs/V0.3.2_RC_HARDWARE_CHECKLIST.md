## J. 急停

在低风险正常状态下触发现有系统急停：

- [ ] 全部电机停止。
- [ ] 左右风扇立即回到停止 PWM 并停用。
- [ ] 电机公开状态为 `EMERGENCY_STOP`，风扇管理器急停锁存。
- [ ] 普通 enabled/模式/姿态心跳不会自动恢复风扇输出。

若电机、风扇任一未停止，立即执行已批准的备用断动力流程，终止本次回归。
