# 项目总览与功能清单

## 1. 项目定位

`imu_cybergear_ros2` 是一个 ROS2 (Jazzy) Python 功能包，将 WIT 维特智能 IMU 的实时姿态数据转换为 4 台小米 CyberGear 电机的联动位置控制。典型应用：自稳平台、遥控云台。

当前 package 发布候选版本：**0.3.2**。本页保留早期 v0.2 功能分区；
v0.3.2 的完整能力、安全语义和验证边界以 package `README.md` 及根目录
`docs/RELEASE_NOTES_v0.3.2.md` 为准。

## 2. 当前实现功能

### 2.1 感知链路

1. 串口读取 WIT IMU 数据帧（0x51/0x52/0x53），支持断线自动重连（指数退避）。
2. 解析后发布标准 `sensor_msgs/Imu` 话题（默认 `/imu/data_raw`）。
3. 发布 IMU 连接状态到 `/imu/status` 话题。

### 2.2 控制链路

1. 订阅 IMU 姿态，AUTO 模式下的闭环位置跟随。
2. 死区过滤、软限位、最大步长平滑、命令频率控制。
3. 支持 4 个电机（ID1~ID4）的独立软限位。
4. **【v0.2 新增】控制状态机**：UNINITIALIZED → INITIALIZING → AUTO_RUNNING / MANUAL_RUNNING / EMERGENCY_STOP / ERROR / SHUTTING_DOWN。

### 2.3 安全机制（v0.2 新增）

1. **通信看门狗**：IMU 数据超时（默认 200ms）自动切手动模式。
2. **三重急停通道**：键盘空格 / 话题 `/e_stop` / 服务 `/e_stop`。
3. **远程启停服务**：`/enable_motor` (std_srvs/SetBool)。
4. **电机反馈监控**：实时读取位置/速度/力矩/温度/运行模式/故障标志。
5. **故障自动保护**：CAN ID 故障标志位触发电机保护。

### 2.4 通信后端

1. `usb_can_serial`：USB-CAN 串口 AT 协议。
2. `socketcan_hat`：Linux SocketCAN（微雪 2-CH CAN HAT+）。

### 2.5 键盘控制

1. 通用控制：`m`/`z`/`x`/`h`/`p`/空格/`r`/`q`。
2. MANUAL 步进：`w/s`、`a/d`、`i/k`、`j/l`。
3. 电机选择：`1`/`2`/`3`/`4`。
4. 选中电机调速：`+`/`-`（兼容 `=`、`_`）。
5. 选中电机快捷动作：`[` 转 +90°，`]` 转 -90°（受软限位约束）。
6. **【v0.2 新增】`p` 键**：发布完整状态汇总（含位置/速度/力矩/温度/故障）。

### 2.6 运行模式

1. 单命令一键启动（默认同时启动 IMU + 控制节点）。
2. 双终端分开启动（推荐调试，键盘更稳定）。

## 3. 关键参数

### 3.1 通信参数
`control_backend`、`usb_port`、`usb_baud`、`can_channel`、`can_bustype`

### 3.2 控制参数
`deadband_rad`、`max_position_step`、`command_interval_sec`、`default_speed`

### 3.3 电机映射
`left_lift_motor_id`(4)、`left_pitch_motor_id`(3)、`right_pitch_motor_id`(2)、`right_lift_motor_id`(1)

### 3.4 方向与软限位
`roll_axis_sign`、`pitch_axis_sign`、`left/right_*_sign`、`m1_min~m4_max`

### 3.5 安全参数（v0.2 新增）
`watchdog_timeout_ms`(200)、`motor_temp_limit_degC`(80)、`motor_temp_critical_degC`(90)、`motor_current_limit_a`(5.0)、`position_error_threshold_rad`(0.3)、`reconnect_on_disconnect`

## 4. 远程控制接口（v0.2 新增）

```bash
# 急停
ros2 topic pub /e_stop std_msgs/msg/Bool "data: true" -1
ros2 service call /e_stop std_srvs/srv/Trigger

# 远程启停
ros2 service call /enable_motor std_srvs/srv/SetBool "data: false"  # 停
ros2 service call /enable_motor std_srvs/srv/SetBool "data: true"   # 启

# 查看电机状态
ros2 topic echo /motor/status
```
