# 环境搭建到调试运行手册

本文中的 CAN、串口、launch 和电机操作会访问真实硬件。执行前必须获得明确
授权并满足 WindArmor 仓库根目录 `AGENTS.md` 的硬件安全门槛。

## 1. 依赖安装

```bash
sudo apt update
sudo apt install -y python3-serial python3-can
```

## 2. 编译

```bash
cd ~/workspace/WindArmor
source /opt/ros/jazzy/setup.bash
colcon build --symlink-install
source install/setup.bash
```

## 3. 开机一次性初始化（仅 CAN HAT+）

如果你使用微雪 CAN HAT+（`socketcan_hat`），请在每次系统开机后执行一次：

```bash
sudo ip link set can10 down
sudo ip link set can10 up type can bitrate 1000000
sudo ip link set can10 txqueuelen 1000
```

> **重要：第三条 `txqueuelen 1000` 必须加上！** 默认发送缓冲区只有 10 帧，
> 连续初始化 4 台电机会报 `No buffer space available [Error 105]`。
> `txqueuelen` 是通用网卡参数，不属于 `type can`，所以必须单独一行设置。

说明：
- 这三条命令是"每次开机一次性动作"。
- 之后同一次开机周期内，不需要在每个终端重复执行。

## 4. 两种连接方式的可复制命令

### 4.1 CAN-USB（usb_can_serial）

单终端：

```bash
cd ~/workspace/WindArmor
source /opt/ros/jazzy/setup.bash
source install/setup.bash
ros2 launch imu_cybergear_ros2 imu_cybergear_system.launch.py \
  control_backend:=usb_can_serial
```

双终端：

终端 A（仅 IMU）：

```bash
cd ~/workspace/WindArmor
source /opt/ros/jazzy/setup.bash
source install/setup.bash
ros2 launch imu_cybergear_ros2 imu_cybergear_system.launch.py start_controller:=false
```

终端 B（仅控制器，自动生命周期转换）：

```bash
cd ~/workspace/WindArmor
source /opt/ros/jazzy/setup.bash
source install/setup.bash
ros2 launch imu_cybergear_ros2 imu_motor_controller.launch.py \
  control_backend:=usb_can_serial
```

## 5. 键盘操作

### 5.1 模式与全局

| 按键 | 功能 |
|------|------|
| `m` | 切换 AUTO / MANUAL 模式 |
| `z` | IMU 姿态归零（当前姿态设为零点） |
| `x` | 全部电机当前位置设为零点 |
| `h` | 自动归零（按一次持续归位，到达自动停止） |
| `p` | 发布当前状态汇总（位置/速度/力矩/温度/故障） |
| `空格` | 急停全部电机 |
| `r` | 仅从普通急停恢复到 MANUAL；不能恢复 ERROR |
| `q` | 退出节点 |

### 5.2 MANUAL 步进

| 按键 | 电机 |
|------|------|
| `w` / `s` | ID3 左俯仰 |
| `a` / `d` | ID4 左抬升 |
| `i` / `k` | ID2 右俯仰 |
| `j` / `l` | ID1 右抬升 |

### 5.3 选中电机操作

| 按键 | 功能 |
|------|------|
| `1` / `2` / `3` / `4` | 按 CAN ID 选中电机 |
| `+` / `=` | 加速 |
| `-` / `_` | 减速 |
| `[` | +90° 快捷位 |
| `]` | -90° 快捷位 |

## 6. 远程控制接口（v0.2 新增）

```bash
# 急停（三种方式等效）
ros2 topic pub /e_stop std_msgs/msg/Bool "data: true" -1
ros2 service call /e_stop std_srvs/srv/Trigger

# 远程启停
ros2 service call /enable_motor std_srvs/srv/SetBool "data: false"
ros2 service call /enable_motor std_srvs/srv/SetBool "data: true"

# 查看电机实时状态
ros2 topic echo /motor/status
# 输出格式: motor_id,pos_rad,speed_rad_s,torque_nm,temp_C,mode,fault_hex

# 动态修改参数
ros2 param set /imu_motor_controller_node watchdog_timeout_ms 500
```

## 7. 速度参数说明

1. `manual_speed_max` 当前为 `20.0 rad/s`，限制 `+/-` 可设置的 CyberGear
   位置模式速度上限。
2. MANUAL、AUTO 与 HOME 的软件目标变化率分别由三个
   `*_motion_speed_rad_s` 参数控制，当前默认均为 `4.0 rad/s`。
3. 唯一固定周期推进器按真实 monotonic `dt` 计算允许步长，并同时受当前模式
   速度、电机速度上限、`motion_dt_max_sec` 和 `max_position_step` 限制。
4. 这些参数不是负载下实测机械角速度；修改前需要独立评估和验证。

## 8. 最快排查（电机不动）

1. 是否选择了正确后端（`usb_can_serial` 或 `socketcan_hat`）
2. CAN HAT+ 是否完成"开机一次性初始化"（含 `txqueuelen 1000`）
3. 若使用双终端模式，终端 A 的 IMU 节点是否已启动
4. 是否已按 `m` 切换到 AUTO 模式
5. 是否误触空格进入急停状态（按 `r` 恢复，再按 `m` 切 AUTO）
6. 键盘焦点是否在控制节点终端
